# Homepage visualisations

`r44-circulant-colouring.png` is a browser-renderable reconstruction of the paper's illustrative circulant $(4,4)$-colouring of $\mathcal{K}_{17}$. It is generated from `r44-colouring-k17.txt` by `render_circulant_colouring.py`.

The matrix uses `0` for blue and `1` for red. Its two circular graphs have the paper distance sets $D_{17}^b=\{3,5,6,7\}$ and $D_{17}^r=\{1,2,4,8\}$. Both colour classes avoid $\mathcal{K}_4$.
