Ramsey numbers.

What is a Ramsey number? R(m,n) is the smallest number of vertices such that every red–blue colouring of the edges of a complete graph contains either a blue clique on m vertices or a red clique on n vertices.

A clique is a set of vertices with every pair joined. A monochromatic clique has all those edges in the same colour.

The first example

R(4,4) = 18. With eighteen vertices, a blue or red clique on four vertices is unavoidable. With seventeen, a colouring can avoid both, as the graph shows.

First proved by Greenwood and Gleason (1955); see Radziszowski, Small Ramsey Numbers, §2.1(b).

01 / Searching in graph families

Give the search some structure.

There are enormously many ways to colour a complete graph. We can search within a family with a compact description, such as circulant graphs. Every valid counterexample we find still proves a lower bound for the ordinary Ramsey number.

The restriction makes the search smaller. A failed search within this family does not rule out counterexamples in other families.

02 / Build a circulant graph

Many edges.
Just a few choices.

Arrange the vertices on a circle. Choose circular distances and join every pair at those distances. Rotating the vertices preserves the graph.

The circular distance is the shorter number of steps around the circle. There are ⌊N/2⌋ possible distances on N vertices. Selecting a distance adds its entire class of edges.

03 / Turn the graph into a colouring

One graph. Its complement.
A possible counterexample.

Colour the selected edges blue and every missing edge red. Instead of choosing colours for all N(N−1)/2 edges, you now have just ⌊N/2⌋ distance colours.

Avoid a blue clique on m vertices and a red clique on n vertices. If both conditions hold on N vertices, the colouring proves R(m,n) ≥ N+1. Change a distance below and see whether the counterexample survives.

What does a valid colouring prove?

A colouring on N vertices with no blue clique of order m and no red clique of order n proves R(m,n) ≥ N+1. Establishing the exact value also requires a matching upper bound.

The 17-vertex construction is a classical example for R(4,4), rather than a new result of this project. The examples on 5 and 6 vertices illustrate R(3,3) = 6. Edits in this demo explore circulant colourings only.

The project / From research to code

A project to read,
check and build on.

This website accompanies the paper An Integer Programming Approach to Compute Lower Bounds for Ramsey Numbers Using Circulant Graphs.

The repository brings together code, instructions, certificates and visualisations. The solver combines integer programming with clique search; a second engine explores circulant colourings without a linear programming model.
