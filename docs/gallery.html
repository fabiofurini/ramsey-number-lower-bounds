Graph gallery / Reading the constructions

One colour shown.
Two colours checked.

These drawings show the blue edges of circulant Ramsey colourings. Every missing edge is red: the two colour classes together form the complete graph.

01 / Blue graph

Read the visible edges.

A label R(m,n) means that the blue graph avoids Km: no set of m vertices has every pair joined by a blue edge.

02 / Red complement

Read the missing edges.

The missing edges form the red graph, which avoids Kn. Equivalently, the blue graph has no independent set of n vertices: a set with no blue edge between any pair.

03 / Lower bound

Read the counterexample.

Both conditions hold on N vertices, so the colouring proves R(m,n) ≥ N+1. The drawing illustrates the construction; the source certificate supports independent verification.

The 17-vertex example

For R(4,4), the blue graph has no clique of four vertices and no independent set of four vertices. The latter condition excludes a red K4. This gives a counterexample on 17 vertices and proves R(4,4) ≥ 18.

The five-vertex and 17-vertex colourings are classical introductory examples. The gallery also includes constructions from the project’s certificate collection; the paper’s 25 improved R(3,n) bounds are listed on the results page.
