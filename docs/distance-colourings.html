Distance colourings · Toeplitz graphs

Ramsey colourings.
Along a line.

The same Ramsey question. A larger family. R(m,n) is the smallest number of vertices such that every red–blue colouring of the edges of a complete graph contains either a blue clique on m vertices or a red clique on n vertices.

Put the vertices at positions 0, 1, …, N−1. Give every edge of the same linear distance |i−j| the same colour. The blue graph is a Toeplitz graph; the red graph is its complement.

The first example

R(4,4) = 18. With eighteen vertices, a blue or red clique on four vertices is unavoidable. With seventeen, a colouring can avoid both, as the graph shows.

First proved by Greenwood and Gleason (1955); see Radziszowski, Small Ramsey Numbers, §2.1(b).

Our research searches for colourings that avoid both forbidden cliques.
Each verified construction proves a lower bound on a Ramsey number. This page explores the linear-distance extension implemented after the paper.

01 / Searching in graph families

Give the search some structure.

A linear-distance colouring needs only N−1 colour choices for N(N−1)/2 edges. Edges with equal differences share a colour. Every valid counterexample found in this family still proves a lower bound for the ordinary Ramsey number.

Every circulant colouring is also a linear-distance colouring: set the colours of d and N−d equal. Here you may change them independently. The familiar examples below start with that equality, and your edits can explore the larger family.

02 / Build a linear-distance graph

Many edges.
Just a few choices.

Arrange the vertices on a line. Select a difference d and join all pairs i, i+d. The arcs bend above the line so equal lengths are easy to follow.

The distance is d = |i−j|, with no wrap-around. There are N−1 possible distances. Distance d has exactly N−d edges: on 17 vertices, distance 1 has 16 edges and distance 16 has just one.

03 / Turn the graph into a colouring

One graph. Its complement.
A possible counterexample.

Colour the selected edges blue and every missing edge red. Instead of choosing colours for all N(N−1)/2 edges, you now have just N−1 distance colours.

What does a valid colouring prove?

A colouring on N vertices with no blue clique of order m and no red clique of order n proves R(m,n) ≥ N+1. Establishing the exact value also requires a matching upper bound.

The 17-vertex construction is a classical example for R(4,4), rather than a new result of this project. The examples on 5 and 6 vertices illustrate R(3,3) = 6. These presets are classical or paper circulant witnesses, embedded in the linear-distance family. Editing distance d does not change N−d. This page does not claim new distance-colouring results.

From circles to differences

More freedom. The same certificate.

Equal distance, equal colour.

The edges (0,3), (1,4) and (2,5) all have distance 3 and change together. The colour only depends on |i−j|. Blue arcs are drawn above the line and red arcs below; their curvature is just a visual aid.

A larger search space.

Circulant colourings require d and N−d to have the same colour. Linear-distance colourings drop that constraint: N−1 binary choices instead of ⌊N/2⌋. More freedom can help a search, but it does not guarantee a stronger bound.

What an exact check proves.

The demo counts blue Kₘ and red Kₙ cliques separately, using the actual linear differences. If both counts are zero, the displayed N-vertex colouring proves R(m,n) ≥ N+1. A forbidden clique can be highlighted directly.

The project / From research to code

A project to read,
check and build on.

This website accompanies the paper An Integer Programming Approach to Compute Lower Bounds for Ramsey Numbers Using Circulant Graphs.

The repository brings together code, instructions, certificates and visualisations. The solver combines integer programming with clique search; a second engine explores circulant colourings without a linear programming model.

The branch-and-cut solver requires a local IBM ILOG CPLEX installation. The currently distributed package uses precompiled objects incorporating COPT. The checker does not require CPLEX. See the repository for requirements and instructions.
